# Even or Odd Checker 🔢

A simple C program that determines whether a user-provided integer is even or odd.

## 📝 Overview
This project demonstrates the use of the modulo operator (`%`) in C, which is a fundamental tool for checking divisibility in programming.

**Concepts covered:**
* **Modulo Operator (`%`):** This operator returns the remainder of a division. If `number % 2` equals `0`, the number is perfectly divisible by 2 (making it even).
* **`if-else` statement:** Basic conditional branching based on the mathematical result.
