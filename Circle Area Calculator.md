# Circle Area Calculator ⭕

A simple and efficient C program that calculates the area of a circle based on a user-provided radius. 

## 📝 Overview
This project demonstrates how to use preprocessor directives (macros) to define constants in C and perform basic floating-point arithmetic. 

**Concepts covered:**
* Using `#define` to create a constant (`PI`).
* Handling floating-point input and output (`float`, `%f`).
* Performing mathematical calculations.

## 💻 How to Run

1. Clone this repository or download the `circle_area.c` file.
2. Open your terminal or command prompt.
3. Compile the code using a C compiler like GCC:
   ```bash
   gcc circle_area.c -o circle_area
